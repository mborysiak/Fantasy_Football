# Normalized Expert-Rank Promotion Decision

## Question

Should the scoring-specific normalized expert-rank level become an active
conditional-PPG feature?

The feature converts each provider's published overall rank to a percentile
within source, season, and position, then takes the cross-source median. DK
uses pinned full-PPR ETR ranks for 2025-2026; beta retains half-PPR ETR.

## Stage A: frozen nested point and distribution test

- Baseline: the current promoted Lasso/RandomForest/LightGBM equal-third point
  model. Its persisted predictions and selections were already generated by
  the production nested whole-season runner.
- Challenger: add only
  `scoring_specific_rank_position_percentile_median` to the identical locked
  feature surface.
- Reselect the complete locked grid independently for Lasso, RandomForest, and
  LightGBM at every 2017-2026 forecast origin.
- Inner scoring uses only whole seasons strictly before the target origin.
- Refit each selected model through `origin - 1`; score 2017-2025.
- Build residual quantiles separately for each arm from strictly earlier OOF
  residual seasons. Score player CRPS and 50%/80% interval coverage over
  2018-2025.
- Current databases are read-only and hash-checked before/after. Parameter
  caches and production locks are not changed.

Stage A advances only if all of these hold:

1. Pooled RMSE and 2023-2025 RMSE improve in both DK and beta.
2. At least five of the six 2023-2025 league-season cells improve.
3. Player-clustered pooled RMSE interval upper bounds are at most zero in both
   leagues.
4. No position worsens by more than 0.01 RMSE in either league.
5. Pooled player CRPS does not worsen in either league.
6. Each 50% and 80% interval is within two percentage points of nominal or
   moves no farther from nominal than production.

## Stage B: frozen downstream transport

Stage B runs only if Stage A passes. It uses the existing role-tier and
fixed-roster validators with unchanged matcher weights, donor eligibility,
participation forecasts, scoring, target cohorts, rosters, rooms, seeds, and
scenario count.

The challenger advances to production preparation only if:

- core and depth player PPG, contribution, and played-game CRPS do not worsen
  by more than 0.25% in any league-period cell;
- fixed-roster score CRPS does not worsen by more than 0.5% in any
  league-period cell; and
- at least three of four development/2023-2025 league-period roster-score
  cells are nonworse.

Championship metrics and 2026 prediction/rank movement are diagnostics. A pass
authorizes implementation and a fresh governed refresh; this study itself
does not modify production.

## Decision

Do not promote normalized expert rank into the current conditional-PPG model.
After full nested reselection, DK improves pooled/recent RMSE by
0.00181/0.00370 and player CRPS by 0.00112, but its player-cluster interval
crosses zero and only 2025 improves among the three recent origins. Beta is
flat-worse by 0.00008 pooled and 0.00004 recent RMSE, worsens player CRPS by
0.00042, and worsens QB RMSE by 0.01280. Only three of six recent
league-season cells improve.

Stage A fails, so the frozen protocol does not authorize Stage B template or
roster replay. Keep the feature in research/audit outputs only. No production
model, cache, template, table, or app artifact changed.
